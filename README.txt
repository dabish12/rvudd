FILES (keep all together, same folder, lowercase names)
  index.html   page
  style.css    design
  script.js    logic
  exam-data.js student accounts + questions (replace it with the file the admin downloads)

PUBLISH ON GITHUB PAGES
  1. New public repository -> upload the 4 files above (the files, not the folder, not the zip).
  2. Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
  3. Open the link, log in as admin (admin / admin123), change the password (Account tab).
  4. Register students, upload questions (PDF or paste), set the time.
  5. Account -> Download exam-data.js -> upload it to the repository (replace the old one).
  6. Give students the link + their username and password.
  Results: students send the result code to the admin; Results -> Import result codes.
  Admin panel on a device that holds student data: add #admin to the link.
